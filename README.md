
# Jogo de Adivinhação em C++

Projeto desenvolvido em C++ para praticar lógica de programação, estruturas condicionais, estruturas de repetição e validação de entradas.

## Funcionalidades

- Geração de um número aleatório entre 1 e 100
- Entrada de palpites pelo jogador
- Dicas indicando se o número secreto é maior ou menor
- Contagem das tentativas realizadas
- Validação de entradas inválidas
- Possibilidade de iniciar uma nova partida

## Tecnologias utilizadas

- C++
- Visual Studio Code
- G++ (GCC)

## Como executar

Compile o arquivo:

```bash
g++ main.cpp -o jogo.exe
```

Execute no Windows:

```powershell
.\jogo.exe
```

## Objetivo

Desenvolver conhecimentos fundamentais de programação em C++ por meio de um projeto prático.
